Privacy Policy – Kedai Matematik

Developer: Zil-el-Saif

Last updated: September 2026

Kedai Matematik ialah aplikasi pendidikan kanak-kanak yang direka untuk dimainkan tanpa akaun, iklan atau penjejakan.

Tiada akaun diperlukan

Aplikasi ini tidak memerlukan akaun atau login. Zil-el-Saif tidak mengumpul nama, alamat e-mel, alamat rumah, nombor telefon atau lokasi pengguna.

Jika pemain memasukkan nama atau memilih profil di dalam aplikasi, maklumat itu kekal pada peranti pemain sahaja dan tidak dihantar kepada developer atau mana-mana server.

Data yang tidak dikumpul

  • Tiada analytics digunakan.
  • Tiada iklan dipaparkan.
  • Tiada tracking atau teknologi penjejakan digunakan.
  • Aplikasi tidak mengakses kamera atau mikrofon.
  • Aplikasi tidak mengakses atau mengumpul lokasi pengguna.
  • Data permainan tidak dihantar ke server luar.

Penyimpanan lokal pada peranti

Progression, stars, settings, statistik permainan dan pilihan profil disimpan secara lokal pada peranti menggunakan storan aplikasi atau browser. Data ini digunakan hanya untuk meneruskan pengalaman permainan pada peranti yang sama.

Kedai Matematik menyokong beberapa profil pemain lokal pada satu peranti. Nama panggilan profil, avatar dan kemajuan pembelajaran disimpan hanya pada peranti dan tidak dihantar kepada kami.

Data lokal boleh dipadam dengan membersihkan data aplikasi atau browser, atau dengan uninstall aplikasi.

Perkongsian dan penyimpanan data server

Kedai Matematik tidak berkongsi data pengguna dengan pihak ketiga. Tiada tempoh penyimpanan data pada server kerana aplikasi tidak menghantar atau menyimpan data permainan pada server.

Privasi kanak-kanak

Aplikasi ini dibina untuk pembelajaran kanak-kanak dengan pendekatan mengutamakan privasi. Ia tidak meminta kanak-kanak menyerahkan maklumat hubungan atau maklumat peribadi kepada developer.

Perubahan kepada polisi ini

Jika amalan privasi aplikasi berubah pada masa hadapan, polisi ini akan dikemas kini dan tarikh kemas kini akan dinyatakan dengan jelas.
